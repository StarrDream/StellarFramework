# Samples / 说明文档

`Samples` 是框架的可运行示例入口。

主要用途：

- 给使用者提供最小接线样例
- 给维护者提供回归验证入口

主要内容：

- `KitSamples`
  各 Kit 的最小运行样例
- `ArchitectureDemo`
  架构协作完整示例

推荐阅读顺序：

1. `快速开始`
2. `UIKit_Playable.unity`
3. `ResKit_Playable.unity`
4. `SettingsKit_Playable.unity`
5. `ArchitectureDemo`

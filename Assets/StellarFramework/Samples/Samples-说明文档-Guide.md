# Samples / 说明文档

Samples 是面向框架使用者的最小教学入口，不是自动化测试、Integration Demo 或发布验收区。

## 内容

- KitSamples：每个 Kit 的最小可运行接线和调用示例。
- ArchitectureDemo：Architecture / Model / Service / View 的教学场景。

样例保持单 Kit、规模小、代码易读、可独立运行和可选导出。它回答“如何使用”，不回答“有没有 Bug”。

## 推荐顺序

1. 快速开始
2. UIKit_Playable.unity
3. ResKit_Playable.unity
4. SettingsKit_Playable.unity
5. ArchitectureDemo
6. 对应 Kit 的说明/源码 Guide

多 Kit 组合、Player、IL2CPP、Addressables、HybridCLR 和真实包体验证见 StellarFrameworkVerification，不在 Samples 中扩展玩法。

# StellarFramework 快速开始

这份文档只负责让新人先跑通框架。深度功能说明请进入 Kit 说明文档；源码实现请进入对应源码文档。

## 第一次打开项目

1. 打开 Unity 菜单 `StellarFramework -> Tools Hub`。
2. 在左侧进入 `Start Here -> Quick Start`。
3. 点击 `构建样例`，生成 KitSamples 需要的场景、资源、UIRoot、示例配置和 AB 示例资源。
4. 先运行 `UIKit_Playable.unity`，确认 UI 门户正常。
5. 再运行 `ResKit_Playable.unity`，确认资源门户正常。
6. 需要资源热更时再进入 `热更新 -> AA 配置与发布`。

## 新项目默认选择

- 架构：用 `Architecture<T>` 管 Model、Service、View。
- UI：只从 `UIKit` 进入，不在业务层直接散落 Instantiate UI Prefab。
- 资源：只从 `ResKit` 分配 loader，不让业务直接关心 Resources、AB、AA。
- 资源热更：这是可选能力。只有导入 `ResKit.Addressables`（以及需要资源热更新时的 `HotUpdate.AddressablesAdapter`）才使用 Addressables；ToolsHub 的 `AA 配置与发布`负责本地内置 AA 和远端热更 AA 的配置、构建、发布和校验。
- 代码热更：这是可选能力。只有导入 `HotUpdate.HybridCLR` 才使用 HybridCLR；运行时先读 `HotUpdateManifest.json`，再加载 DLL 和 AOT metadata。
- 配置、设置、音频、事件：按 `ConfigKit`、`SettingsKit`、`AudioKit`、`EventKit` 的说明文档接入。

## 架构最小模板

```csharp
using StellarFramework;
using StellarFramework.Bindable;
using UnityEngine;

public sealed class GameApp : Architecture<GameApp>
{
    protected override void InitModules()
    {
        RegisterModel(new PlayerModel());
        RegisterService(new PlayerService());
    }
}

public sealed class PlayerModel : AbstractModel
{
    public readonly BindableProperty<int> Hp = new BindableProperty<int>(100);
}

public sealed class PlayerService : AbstractService
{
    public void TakeDamage(int damage)
    {
        PlayerModel model = GetModel<PlayerModel>();
        model.Hp.Value = Mathf.Max(0, model.Hp.Value - damage);
    }
}

public sealed class GameEntry : MonoBehaviour
{
    private void Awake()
    {
        GameApp.Interface.Init();
    }
}
```

View 只读 Model、调用 Service：

```csharp
using StellarFramework;
using UnityEngine;

public sealed class PlayerHudView : StellarView
{
    public override IArchitecture Architecture => GameApp.Interface;

    public override void OnBind()
    {
        this.GetModel<PlayerModel>().Hp.RegisterWithInitValue(OnHpChanged)
            .UnRegisterWhenGameObjectDestroyed(gameObject);
    }

    public void OnClickDamage()
    {
        this.GetService<PlayerService>().TakeDamage(10);
    }

    private void OnHpChanged(int hp)
    {
        Debug.Log($"当前血量: {hp}");
    }

    public override void OnUnbind()
    {
    }
}
```

## UIKit 最小模板

```csharp
using Cysharp.Threading.Tasks;
using StellarFramework.UI;
using UnityEngine;

public sealed class LoginPanelData : UIPanelDataBase
{
    public string DefaultAccount;
}

public sealed class LoginPanel : UIPanelBase
{
    public override void OnOpen(UIPanelDataBase data)
    {
        if (TryGetPanelData<LoginPanelData>(data, out LoginPanelData loginData))
        {
            Debug.Log(loginData.DefaultAccount);
        }
    }
}

public sealed class UIEntry : MonoBehaviour
{
    private async UniTaskVoid Start()
    {
        await UIKit.Instance.InitAsync();
        await UIKit.OpenAsync<LoginPanel>(new LoginPanelData { DefaultAccount = "player01" });
    }
}
```

## ResKit 最小模板

```csharp
using Cysharp.Threading.Tasks;
using StellarFramework.Res;
using UnityEngine;

public sealed class PrefabSpawner : MonoBehaviour
{
    private IResLoader _loader;
    private const string PrefabPath = "Assets/Game/Prefabs/Hero.prefab";

    private async UniTaskVoid Start()
    {
        _loader = ResKit.Allocate(ResLoaderRequest.Custom("Addressables", nameof(PrefabSpawner)));
        GameObject prefab = await _loader.LoadAsync<GameObject>(PrefabPath, destroyCancellationToken);

        if (prefab != null)
        {
            Instantiate(prefab);
        }
    }

    private void OnDestroy()
    {
        if (_loader == null)
        {
            return;
        }

        _loader.Unload(PrefabPath);
        ResKit.Recycle(_loader);
        _loader = null;
    }
}
```

## 热更新最小路线

本地内置 AA：

1. 打开 `Tools Hub -> 热更新 -> AA 配置与发布`。
2. 选择 `本地内置 AA`。
3. 点击 `一键本地内置构建`。
4. 打包 Player，资源随包进入 `StreamingAssets/aa`。

远端热更 AA：

1. 打开 `Tools Hub -> 热更新 -> AA 配置与发布`。
2. 选择 `远端热更 AA`。
3. 设置远端发布目录或 URL。
4. 点击 `一键远端热更发布`。
5. Player 启动时通过 `HotUpdateManifest.json` 读取本次 DLL、metadata、catalog 和 bundle 信息。

资源版本、catalog hash、bundle 下载和缓存由 Addressables 官方机制负责；`HotUpdateManifest`、DLL SHA256 校验和 HybridCLR 入口加载由框架负责。

继续阅读：[HotUpdateKit 说明文档](Runtime/Kits/HotUpdateKit/HotUpdateKit-热更新-说明文档-Guide.md) 和 [HotUpdateKit 源码文档](Runtime/Kits/HotUpdateKit/HotUpdateKit-热更新-源码文档-Guide.md)。

## 常见排错

- Quick Start 没有样例场景：重新点击 `构建样例`。
- UI 打不开：检查 `UIKitSettings`、`UIRoot`、面板 Prefab 路径和加载后端。
- Addressables 同步加载返回空：生产 AA 使用 `LoadAsync<T>`。
- AB 加载失败：先运行 ToolsHub 的 `资源打包 (AssetBundle)`，再确认 `AssetBundleManager.InitAsync()` 已执行。
- 远端热更没更新：检查远端目录里的 catalog、hash、bundle、`HotUpdateManifest.json` 是否同批次生成。
- DLL SHA256 mismatch：重新执行同一页签的一键发布，确保 Manifest 和 DLL 来自同一批。

## 生产热更新规则

- 编辑器和 Development Build 会尽量保留提示与兜底，方便你先把链路跑通。
- 正式发布构建会切到严格模式，以下条件不满足就会直接阻断启动：
  - `HotUpdate.dll.bytes` 必须带有正确的 `SHA256`
  - `HotUpdateManifest.json` 必须来自显式地址，或来自 `StreamingAssets`
  - 不允许只靠 `Resources` 默认配置偷偷兜底
- 最稳的做法是：每次发版都先通过 Tools Hub 重新导出 `dll.bytes` 和 `HotUpdateManifest.json`，再一起发布。
- 生产放行前必须在目标平台的 IL2CPP Player 上完成一次真实下载、校验、metadata 加载、热更入口执行和回滚验证；编辑器里的示例入口检查不能替代这一步。
